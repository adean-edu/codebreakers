The concepts

Words to know

Cipher

A way of scrambling a message so only someone with the key can read it.

Enigma

The cipher machine Germany used for military messages.

Ultra

The code name for intelligence from the highest-level German ciphers, such as Enigma.

Cover story

A believable explanation, like a patrol plane’s sighting, for how you really knew something.

Double agent

A spy who seems to work for one side while secretly working for the other.

Need to know

Share a secret only with the people who must have it to do their job.

These six words come up again and again in the game. A cipher scrambles a message. Enigma was Germany's cipher machine. Ultra was the British code name for intelligence from broken German ciphers. A cover story explains how you knew something without revealing the real source. A double agent pretends to spy for one side while working for the other. And "need to know" was the rule for keeping secrets small: only tell people who must know. Each round also introduces more terms.
