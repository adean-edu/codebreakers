The Navajo Code Talkers

The US Marines needed a code the Japanese could never break, so they turned to the Navajo language.

  • 29 → about 400: twenty-nine Navajo Marines created the code in 1942. About 400 served as code talkers.
  • Never broken: at Iwo Jima they sent more than 800 messages in two days without an error.
  • Kept secret until 1968. In 2001 the original 29 received the Congressional Gold Medal.
This story isn't in the game, but it is one of the great codebreaking stories of the war, and in this one the code was never broken. This photo shows Navajo Marines on Saipan in June 1944. In 1942, twenty-nine Navajo recruits in the US Marines created a code based on their language, with code words for military terms, like "iron fish" for submarine. About 400 Navajo eventually served as code talkers in the Pacific. At Iwo Jima, six code talkers sent and received more than 800 messages in the first two days of the battle without a mistake. The program stayed classified until 1968, and in 2001 the original 29 were awarded the Congressional Gold Medal. Code talkers from other nations, including the Comanche and Choctaw, served too.
